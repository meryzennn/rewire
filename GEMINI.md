# Project Rules (Rewire)

## 1. RTK (Rust Token Killer)
- Always prefix shell/terminal commands with `rtk` (e.g. `rtk git status`, `rtk git diff`, `rtk flutter test`, `rtk rg`).

## 2. Ponytail (Anti-Overengineering & YAGNI)
- Follow Ponytail principles on all coding tasks: YAGNI, shortest working diff, native/standard library first, minimal boilerplate, no unrequested abstractions.
